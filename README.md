# Ali Rahujo — Personal Portfolio

A responsive, dark red-neon portfolio built with HTML, CSS and vanilla JavaScript.

## Included
- Responsive navigation for desktop and mobile
- Red / crimson / black palette inspired by the supplied reference image
- Animated floating skill labels and CSS 3D-style hero treatment
- Pointer-responsive hero tilt (desktop)
- Filterable grid for all 17 learning areas
- About, learning journey, projects, financial-market interests, creative gallery, certificates and contact sections
- Reduced-motion support, semantic landmarks, descriptive image text and SEO metadata

## Run locally
1. Extract the ZIP file.
2. Open the `ali-rahujo-portfolio` folder.
3. Double-click `index.html` to open it in a modern browser.

For a local development server, open a terminal in this folder and run:
- Python: `python -m http.server 8000`
- Then visit `http://localhost:8000`

## Publish online
### GitHub Pages
1. Create a GitHub repository, for example `ali-rahujo-portfolio`.
2. Upload the contents of this folder (keep `index.html`, `css`, `js` and `assets` together).
3. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

You can also deploy the folder using Netlify or Cloudflare Pages.

## Personalize later
- Replace `assets/ali-hero-reference.png` with a new image if you want a different hero visual.
- Add real GitHub / LinkedIn / Instagram URLs when ready.
- Add project cards only after you have actual work to show.
- Add certificates only after you earn them.
- Update each skill's status and description to match what you can currently demonstrate.
- Consider adding a GitHub profile link and project demo links.

## Accuracy note
All listed areas are presented as learning interests or developing skills. No employment, professional expertise, completed projects, certificates or trading performance is claimed.
